The Transformer is the first sequence-transduction model built entirely from attention — no recurrence, no convolution — and it beats every prior WMT 2014 translation result (28.4 BLEU EN→DE, 41.8 EN→FR) at a fraction of the training cost because every position is processed in parallel.

This is the root of the LLM milestone path: BERT is this paper’s encoder stack, GPT is its decoder stack, and essentially every modern LLM is these same blocks scaled up. Understanding why each piece here is forced explains most architecture decisions of the following decade.

Motivation

The dominant sequence transduction models are recurrent: they compute hidden state hth_tht​ from ht−1h_{t-1}ht−1​, so computation inside one training example is inherently sequential — positions cannot be processed in parallel, and at long sequence lengths memory limits how many examples can be batched (§1). Convolutional escapes (ByteNet, ConvS2S) do parallelize, but the number of operations needed to relate two positions grows with their distance — linearly for ConvS2S, logarithmically for ByteNet — which makes long-range dependencies harder to learn (§2). Attention already connected arbitrary positions regardless of distance, but in all but a few cases it was bolted onto a recurrent network, so the sequential bottleneck survived (§1).

Contribution (what’s new)

The bet that survives deleting “we propose”: self-attention alone suffices for state-of-the-art transduction — the first model to compute all its representations without sequence-aligned recurrence or convolution (§2). Three sub-designs are each forced by a specific failure mode:

  • Scaled dot-product attention: for large key dimension dkd_kdk​ the dot products grow (variance dkd_kdk​ for random unit-variance vectors), pushing softmax into regions of vanishing gradient — so scores are divided by dk\sqrt{d_k}dk​​ (§3.2.1, fn.4).
  • Multi-head attention: a single softmax average blurs distinct relations (“averaging inhibits” attending to different representation subspaces), the price the Background section calls reduced effective resolution — so run h=8h=8h=8 small attentions in parallel and concatenate (§2, §3.2.2).
  • Sinusoidal positional encodings added to the embeddings: with recurrence and convolution gone, nothing else tells the model token order (§3.5).

Research questions

  1. Can attention fully replace recurrence and convolution in encoder–decoder transduction without losing quality (§1–2)?
  2. What is gained structurally — per-layer complexity, minimum sequential operations, and the maximum path length between any two positions (§4, Tab.1)?
  3. Which components actually matter: number of heads, key size, model size, dropout, choice of positional encoding (§6.2)?

Methodology

Both encoder and decoder are stacks of N=6N=6N=6 identical layers made of two repeating pieces — multi-head self-attention and a position-wise feed-forward network — each wrapped in a residual connection followed by layer normalization (§3.1). Carry one example through: in “The Law will never be perfect, but its application should be just”, every token emits a query, a key, and a value vector; the token “its” compares its query against all keys, softmax turns the scores into weights, and its new representation is the weighted sum of all values — and a trained head really does sharply pick out “Law” and “application” for “its” (Fig.4, encoder layer 5). Every position does this simultaneously as one matrix multiply — that is where the parallelism comes from. The decoder generates autoregressively, with its self-attention masked (illegal positions set to −∞-\infty−∞ before softmax) so position iii only sees outputs before iii, plus a third sub-layer attending over the encoder output (§3.1–3.2.3).

Main result

Transformer (big) reaches 28.4 BLEU on WMT14 EN→DE — more than 2.0 BLEU above every prior result including ensembles — and the base model alone (27.3) already beats all previously published models and ensembles at a fraction of their training FLOPs (Tab.2, §6.1). BLEU on newstest2014:

Key findings

  • Self-attention gives O(1) sequential operations and O(1) maximum path length between any two positions, versus O(n) for recurrence (Tab.1, §4) — the mechanistic reason both training parallelizes and long-range dependencies get easier; per-layer cost O(n2⋅d)O(n^2\cdot d)O(n2⋅d) is cheaper than recurrent O(n⋅d2)O(n\cdot d^2)O(n⋅d2) whenever sequence length n is below representation size d, the common case with subword vocabularies.
  • Heads follow an inverted U: single-head is 0.9 BLEU below the best setting, but 32 heads is also worse than 8 (Tab.3(A), §6.2) — more heads is not monotonically better.
  • Shrinking the key size d_k hurts quality (Tab.3(B), §6.2) — determining compatibility is not easy, and a smarter compatibility function than dot product may be beneficial (author-stated).
  • Bigger models are better (d_model 1024 → 26.0 dev BLEU; d_ff 4096 → 26.2) and dropout is critical: removing it drops the base model from 25.8 to 24.6 (Tab.3(C,D), §6.2).
  • Learned positional embeddings perform nearly identically to sinusoids (Tab.3(E), §6.2) (25.7 vs 25.8 dev BLEU) — sinusoids were kept only for hoped-for length extrapolation, which is not tested.
  • Label smoothing hurts perplexity (the model becomes less sure) yet improves accuracy and BLEU (§5.4) — perplexity and task quality can move in opposite directions.
  • With almost no task tuning, a 4-layer Transformer generalizes to English constituency parsing: 91.3 F1 training on 40k WSJ sentences alone — beating the BerkeleyParser in the small-data regime where RNN seq2seq had failed — and 92.7 F1 semi-supervised (Tab.4, §6.3).
  • Individual attention heads specialize into interpretable roles (Figs.3–5, §4) — completing the long-distance phrase “making…more difficult”, and resolving “its” to “Law”/“application” (anaphora) — qualitative evidence, no quantitative analysis.

Implications

Removing recurrence turns sequence modeling into large matrix multiplies, which is exactly what accelerators scale — this is the enabling step for the pretraining era. BERT reuses this encoder stack; GPT reuses this decoder stack; tensor2tensor released the reference code. Author-stated next steps: other modalities (images, audio, video), local/restricted attention for very long inputs (Tab.1’s O(r·n·d) row is proposed but never evaluated here), and making generation less sequential (§7). Two threads the ablations open: why head count has an optimum rather than more-is-better, and whether a learned compatibility function beats scaled dot product at small d_k (§6.2).

Limitations

  • Per-layer cost is quadratic in sequence length, O(n²·d) — fine for sentence-length n under d=512, a real cost for long sequences; the restricted-attention fix is future work (§4).
  • Attention’s constant path length is bought by averaging, i.e. reduced effective resolution; multi-head counteracts but does not provably eliminate this (§2).
  • Autoregressive decoding remains sequential at inference — the parallelism win is in training/encoding; “making generation less sequential” is explicitly still a goal (§7).
  • Evaluated only on two translation pairs plus one parsing task; claims about generality beyond text are speculation in the conclusion (§6, §7).
  • The vanishing-gradient explanation for the √d_k scaling is stated as suspicion, not demonstrated (§3.2.1).

Critiques and Questions

  1. Internal inconsistency: §6.1’s text reports 41.0 BLEU for big EN→FR while the abstract and Tab.2 report 41.8 (this v7 extraction contains both) — the headline number depends on which you trust.
  2. Tab.3 ablations are single runs on the dev set (newstest2013) without checkpoint averaging and without variance estimates; several conclusions (head count, d_k) rest on 0.3–0.9 BLEU deltas.
  3. Training-cost comparisons use FLOPs estimated as time × GPUs × an assumed sustained TFLOPS per GPU type (fn.5, p.8) — a rough instrument for the “fraction of the cost” claim.
  4. The interpretability evidence is a handful of hand-picked attention visualizations (Figs.3–5); nothing quantifies how typical those heads are.
  5. Sinusoids are justified by an extrapolation hypothesis that is never tested — and Tab.3(E) shows the choice does not matter on the actual benchmark.
Why are the attention logits divided by the square root of d_k before the softmax?
For random queries/keys with unit-variance components, the dot product has variance d_k, so its magnitude grows with the key dimension; large logits push the softmax into saturated regions with extremely small gradients. Dividing by sqrt(d_k) keeps the logits at unit scale so gradients flow (§3.2.1, fn.4).
