Mamba makes state space model parameters functions of the input (“selection”), which destroys the convolutional shortcut that made prior SSMs fast — so it recovers speed with a hardware-aware fused parallel scan that never writes the expanded state to GPU main memory, yielding the first attention-free architecture to match a strong Transformer recipe on language modeling while scaling linearly in sequence length and running 4–5x faster at inference.

The most credible challenge to attention’s monopoly since 2017: a fully recurrent model with constant-time-per-token generation and no KV cache that holds up on language, not just on synthetic long-range benchmarks. Foundational for anyone tracking long-context architectures, and the origin of the SSM/hybrid line (Mamba-2, Jamba, Zamba, Falcon-Mamba).

Motivation

Sequence modeling forces a single tradeoff: attention is effective precisely because it does not compress context at all — it keeps every token in the KV cache — which is why it costs quadratic time in training and linear memory per generated token, and cannot see beyond a finite window (§3.1). Recurrent models invert this: a fixed-size state buys constant-time inference, but their quality is capped by how well that state compresses history. Structured SSMs (S4 and descendants) seemed to escape the dilemma by expanding the effective state and computing efficiently as a global convolution — but only under a hidden constraint: all prior structured SSMs must be linear time-invariant (their dynamics constant across timesteps) to be computable as convolutions, and an LTI model physically cannot decide based on content what to keep or discard (§2, §3.1). That is why SSMs dominated continuous modalities (audio, vision, Long Range Arena) yet lost to attention on discrete, information-dense text. The failure is visible in two synthetics: the ordinary Copying task (constant spacing) is solvable by time-awareness alone, but Selective Copying (random spacing) and Induction Heads (associative recall of ”…Harry Potter … Harry → ?”) demand content-awareness, and LTI models fail both.

Contribution (what’s new)

Selection: make Δ, B, and C functions of the input token — so the recurrence itself becomes time-varying and can filter, forget, or persist based on content (§3.2, Alg.2). One token of intuition: with a large Δt\Delta_tΔt​ the state resets and absorbs the current input; with Δt→0\Delta_t \to 0Δt​→0 the input is ignored and the state passes through untouched, so “um” in a sentence or 500 noise tokens between two data tokens simply do not enter the state. Theorem 1 shows that classic RNN gating is exactly the 1-dimensional special case of this mechanism — ht=(1−gt)ht−1+gtxth_t = (1-g_t)h_{t-1} + g_t x_tht​=(1−gt​)ht−1​+gt​xt​ with gt=σ(Linear(xt))g_t = \sigma(\mathrm{Linear}(x_t))gt​=σ(Linear(xt​)) — so discretization of a continuous system is the principled origin of heuristic gates (§3.5.1).

The cost is that time-varying dynamics kill the convolutional form, and the naive recurrence must materialize a state of shape (B, L, D, N) — N (≈16) times larger than the input. The fix is a hardware-aware fused kernel: load the compact parameters from HBM to SRAM, discretize and run a work-efficient parallel scan entirely in SRAM, write back only the (B, L, D) output, and recompute intermediate states in the backward pass instead of storing them (§3.3, App.D) — reducing memory IO by a factor of N and making the layer as memory-frugal as FlashAttention. Third, the architecture is simplified: the H3-style SSM block and the Transformer’s MLP block are fused into one homogeneous block (expansion factor E=2, no attention and no separate MLP), stacked uniformly (§3.4, Fig.3).

Research questions

  1. Is content-based selection the missing ingredient that keeps efficient sub-quadratic models from matching attention on discrete data? (§3.1, §4.1)
  2. Can a time-varying (non-convolutional) SSM still be fast on real GPUs? (§3.3, §4.5)
  3. Does a fully recurrent, attention-free model match a modern Transformer recipe on language, and generalize across modalities (DNA, audio) and to million-token contexts? (§4.2–4.4)

Methodology

A structured SSM maps each channel of the input through a latent state ht∈RNh_t \in \mathbb{R}^Nht​∈RN: ht=Aˉht−1+Bˉxth_t = \bar{A}h_{t-1} + \bar{B}x_tht​=Aˉht−1​+Bˉxt​, yt=Chty_t = Ch_tyt​=Cht​, where the discrete (Aˉ,Bˉ)(\bar{A}, \bar{B})(Aˉ,Bˉ) come from continuous (A,B)(A, B)(A,B) via a step size Δ (zero-order hold: Aˉ=exp⁡(ΔA)\bar{A} = \exp(\Delta A)Aˉ=exp(ΔA)). In S4 these are constants; in Mamba’s S6 layer, B and C are linear projections of the input and Δ is a broadcast projection through softplus, so the recurrence changes at every position. Training uses the fused selective scan; inference is a plain recurrence with O(1) state per step and no cache. Evaluation spans synthetics (Selective Copying, Induction Heads), Pile language modeling with Chinchilla-protocol scaling laws (125M–1.3B) and 300B-token models for zero-shot eval (130M–2.8B), human-genome DNA (HG38), and audio waveforms (YouTubeMix, SC09).

Method details: the selective scan, the block, and training setup

Why the state cannot simply be materialized: an SSM applied per channel with state dimension N has total hidden state (B, L, D, N), a factor of N ≈ 16–100 larger than the input (B, L, D). LTI models dodge this by expanding into a convolution kernel of size (B, L, D) instead. Selective SSMs cannot, so the state must live in fast memory only.

  1. 1. Load compact parameters — Read Δ, A, B, C — O(BLN + DN) bytes — from slow HBM into fast SRAM, rather than the expanded (B,L,D,N) tensors.
  2. 2. Discretize in SRAM — Compute the discrete Ā, B̄ of size (B,L,D,N) inside SRAM; they never touch HBM.
  3. 3. Parallel associative scan — The recurrence is sequential but associative, so a work-efficient parallel scan (Blelloch) computes all states in O(L log L) depth with O(BLDN) FLOPs — fewer FLOPs than the convolutional path's O(BLD log L) with a lower constant, for long L and modest N.
  4. 4. Contract and write out — Multiply by C and sum over the state dimension, writing only the (B,L,D) output back to HBM. Net effect: memory IO reduced by a factor of O(N).
  5. 5. Recompute on the backward pass — Intermediate states are not saved; they are recomputed from re-loaded inputs during backprop. Reading them back from HBM would cost more than recomputing, so this is a speedup as well as a memory saving.

For sequences too long to fit SRAM, the scan is chunked, carrying intermediate states across chunks.

Block: each Mamba block is a SwiGLU-style gated MLP with a conv → SSM path added on the main branch (SiLU activation, optional LayerNorm borrowed from RetNet). Most parameters (3ED²) sit in the linear projections; the SSM itself contributes few. Two Mamba blocks are stacked to match the 12D² parameters of one MHA+MLP Transformer layer (§3.4).

Design choices with reasons (§3.6): real-valued state by default (complex helps only on continuous modalities — used solely in the audio experiment); S4D-Real initialization; only Δ, B, C are made selective — A affects the model only through Aˉ=exp⁡(ΔA)\bar{A} = \exp(\Delta A)Aˉ=exp(ΔA), so selectivity in Δ already induces selectivity in Aˉ\bar{A}Aˉ.

Training (App.E.2): Pile, GPT-2 tokenizer for scaling laws (GPT-NeoX for the 300B-token models), AdamW, cosine schedule, gradient clip 1.0, weight decay 0.1, no dropout. The Transformer++ baseline gets rotary embeddings, SwiGLU, RMSNorm, no linear biases, and 5x the GPT-3 peak learning rate — the strongest Transformer recipe the authors know of, and Mamba is given the same improved recipe.

Main result

Mamba is the first attention-free model to match Transformer++ on Pile scaling laws from 125M to 1.3B parameters, with the gap widening in Mamba’s favor as context grows from 2K to 8K (Fig.4), while Hyena, RWKV, RetNet, and H3++ all trail. Downstream, quality transfers:

Key findings

  • Selection, not architectural gating, is what solves content-aware tasks: on Selective Copying, S6 reaches 97.0–99.8% in any block while every LTI layer stalls at 18–57% (S4 18.3, H3+S4 57.0, Hyena 30.1); on Induction Heads, Mamba trained at length 256 stays at perfect accuracy out to 2^20 = 1M tokens while attention (even with xPos), H3, and Hyena all collapse past ~512–1024 (Tab.1, Tab.2/11). The authors explicitly reject the common claim that multiplicative gating confers “data-dependence” — gating does not interact along the sequence axis and cannot change token spacing (§4.1.1, App.A).
  • Δ is the single most important selective parameter (9.81 ppl alone vs 10.93 with none), but the three synergize far beyond their individual effects (all three: 8.71) (Tab.7) — consistent with Theorem 1’s identification of Δ with gating.
  • State expansion only pays off when B and C are selective: with fixed B, C, growing N from 1 to 16 buys 0.07 ppl (9.88→9.81); with selective B, C the same growth buys over 1.0 ppl (9.73→8.71) for ~1% more parameters (Tab.10) — the empirical core of the paper’s “bigger state is better, if you can choose what enters it” thesis.
  • The block design barely matters; the inner layer is everything. Mamba+S6 (8.69) vs H3+S6 (8.95) is a small gap, while every LTI inner layer clusters near 10.2–10.8 regardless of block. Interleaving Mamba with MHA helps only slightly, and with plain MLPs hurts only slightly (Tab.6, Fig.9) (App.E.2.2) — notable because prior work found big gains from adding attention to LTI SSMs.
  • Longer context genuinely helps Mamba: on DNA its perplexity keeps improving out to 1M-token sequences while HyenaDNA gets worse, and on great-apes classification (5 species sharing 99% of DNA) accuracy rises with context to 81.3% at 1M tokens (7M-param Mamba) vs HyenaDNA’s 54.9% (Fig.5, Fig.6, Tab.13). LTI models cannot ignore irrelevant history, so a very long convolution kernel just aggregates noise.
  • Honest negative result: selection hurts on audio waveforms — a uniformly sampled, smooth continuous signal where LTI inductive bias is correct — and the complex-valued S4 parameterization still wins there (Fig.10, §5). The gap shrinks when only the U-Net’s inner (already-pooled, “tokenized”) blocks are made selective, supporting a continuous-discrete spectrum rather than a universal win. Even so, Mamba-UNet halves SC09 speech-generation FID vs SaShiMi (0.94 vs 1.99 at ~6M params; 0.67 at 24M), beating much larger GAN and diffusion baselines (Tab.4).
  • Efficiency is real, not asymptotic hand-waving: the fused scan beats FlashAttention-2 beyond 2K length (up to ~7x at 32K) and is 20–40x faster than a naive PyTorch scan, while training memory matches an optimized Transformer (4.8GB vs 4.6GB at batch 1) (Fig.8, Tab.15). Inference throughput gains come from the absence of a KV cache allowing much larger batches (Mamba-6.9B: 515 tok/s at batch 128 where Transformer-6.7B OOMs past batch 16 at 120 tok/s).

Implications

If selection is the missing ingredient, the field’s decade-long “efficient attention” search was aimed at the wrong target: the problem was never the cost of attention but the inability of cheap alternatives to choose. Mamba unifies the S4/S5/DSS structured-SSM line with the gated-RNN tradition (LSTM/GRU, QRNN, SRU) via Theorem 1, and positions H3, Hyena, RetNet, and RWKV as LTI special cases that inherit the same blind spot. The practical payoff — constant memory per generated token — reframes long-context serving economics, and the hardware-aware-algorithm methodology continues the FlashAttention thesis that IO, not FLOPs, sets the frontier. Whether the advantage survives at 7B+ scale is the paper’s own biggest open question; whether SSMs support the Transformer ecosystem’s affordances (in-context learning, instruction tuning, RLHF, quantization, LoRA) is entirely untested here; the audio result suggests hybrid stacks where outer layers stay LTI and inner layers are selective; and the fixed-size state must eventually lose to attention on exact long-range recall — where that boundary lies is the question later Mamba-vs-Transformer copying/recall studies pursued.

Limitations

  • Scale: scaling laws stop at 1.3B and downstream models at 2.8B, below the 7B scale at which RWKV, RetNet, and Llama were evaluated; the authors note that scaling SSMs may require further engineering not discussed here (§5).
  • No free lunch: selection degrades performance on continuous modalities (audio waveforms), where LTI and complex-valued parameterizations remain better (§5, Fig.10) — Mamba is not a universal replacement.
  • Downstream affordances (fine-tuning, prompting, in-context learning beyond induction heads, RLHF, quantization) are explicitly unexamined (§5).
  • Evaluations are all pretraining-quality and zero-shot commonsense; no instruction-following, reasoning, code, or long-context retrieval benchmarks on natural text (inferred from §4.2).
  • Several results are single-run with tuned-per-model learning rates (Mamba’s optimal DNA LR of 8e-3 sits at the top of the swept range and may still be suboptimal), and induction-heads baselines were reported at different epoch counts (App.E.1, E.3.2).

Critiques and Questions

  1. The strongest claim — “Transformer-quality” — rests on perplexity and six zero-shot commonsense tasks. Those are exactly the metrics a well-compressed state does well on. The tasks that should most stress a fixed-size state (multi-fact retrieval over long natural-language context, in-context copying of arbitrary strings) are tested only in the synthetic induction-heads setting, where the vocabulary is 16 tokens.
  2. Induction-heads extrapolation to 1M is a striking demonstration but a favorable one: a 2-layer, 74K-parameter model on a task with one relevant bigram. Attention baselines OOM past 16K, so the comparison at 1M is against nothing.
  3. Some baseline comparisons are underpowered by the authors’ own admission — RWKV and RetNet lack 8K-context results due to missing efficient implementations, and Hyena’s induction-heads model carries 69M parameters (mostly positional encodings) against Mamba’s 74K, so those rows are not like-for-like.
  4. The Mamba block is largely a SwiGLU MLP with a conv→SSM path added, and the ablations show block choice barely matters. The architecture section is therefore closer to simplification than contribution; the real content is the S6 layer plus the kernel.
  5. The scan’s O(BLDN) FLOPs beat convolution’s O(BLD log L) only “for long sequences and not-too-large state dimension N” — the crossover is asserted rather than mapped, and all benchmarks fix N=16.
Why can't prior structured SSMs (S4, H3, Hyena) simply be made input-dependent, and what breaks if you do it naively?
Their efficiency depends on linear time-invariance: with constant (Δ, A, B, C) the recurrence unrolls into a single global convolution whose kernel is only (B, L, D), so the N-times-larger latent state never has to be materialized. Making the parameters input-dependent makes the dynamics time-varying, which destroys the convolutional form and forces the recurrent path — whose naive implementation must write the (B, L, D, N) state to GPU HBM, making it memory-bandwidth bound and impractically slow. Mamba's fused selective scan resolves this by materializing that state only in SRAM and recomputing it in the backward pass, cutting IO by a factor of N.
