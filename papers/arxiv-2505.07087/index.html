Three cognitive-architecture veterans argue that cognitive design patterns are a productive analytic lens on Agentic LLM systems, and use the lens to audit two well-known systems, name two patterns the LLM-agent field has skipped, and nominate one pattern that is genuinely new to LLMs.

Direct ammunition for the TDE related-work section, arriving from the opposite tradition: this paper independently names the two gaps TDE attacks — Agentic LLM loops make no explicit commitment (ReAct maps onto observe-decide-act minus the commit step) and have no reconsideration / belief-revision mechanism — and it flags that the LLM-native substitute, step-wise reflection, is self-adjudicated, “as potentially unreliable as the initial response” and possibly unbounded (§3.3, p.9). TDE reads as the missing external arbiter for exactly that slot: the runtime acceptance suite over the final world state is the explicit commitment, red-green iteration is reconsideration, and mechanical environment-computed grading supplies the “external/oracular feedback” this paper says step-wise reflection lacks. It differs in kind, not degree: ten pages of analysis with no executable gating, no pre/postconditions, no benchmark, no experiment.

Motivation

More than one hundred cognitive architectures have been built in largely disparate traditions (§1, p.1), and although they have converged on a shared functional picture of cognition, that accumulated knowledge is not transferring into the Agentic LLM field, which is growing fast without a shared vocabulary for what its systems functionally do. The authors argue the transfer fails because of the level at which comparison usually happens: comparing implementations hides commonality — saying “Soar uses a JTMS” and “this BDI architecture runs decision-theoretic calculations over memory instances” makes it easy to miss that both occupy one functional role, reconsideration and more broadly belief revision (§2, p.4). Comparison at the level of whole architectures, meanwhile, is too coarse to say anything actionable. Prior calls to draw lessons from cognitive architecture for LLM agents (Sumers et al.’s CoALA, Sypherd and Belle) are acknowledged but characterized as high-level proposals rather than fine-grained comparative instruments (§1, p.2).

Contribution (what’s new)

The delta is an abstraction level, not a system. Name the functional role and drop the algorithm: a cognitive design pattern is the reusable slot (reconsideration, knowledge compilation, episodic memory, 3-stage commitment), and any architecture either fills it, fills it partially, or leaves it empty. The design must take this form precisely because the two available alternatives fail in opposite directions — implementation-level comparison obscures shared function, architecture-level comparison yields no testable claims. The second delta is using the catalog as a diagnostic that converts “this system is missing something” into named, falsifiable research questions: ReAct has no commitment step, so would adding one improve reasoning?; Generative Agents’ memory satisfies 3 of 9 episodic-memory criteria, so what changes if agents can deliberately construct retrieval cues? The third, smaller delta is a claim that the traffic runs both ways — LLMs, which intermix content and control rather than obeying a fixed control flow, can generate patterns cognitive architecture never had (§3.3, p.9).

Research questions

Stated explicitly (§3, p.4): (1) Which cognitive design patterns are already evident in Agentic LLM systems? (2) Which patterns look apt for Agentic LLMs but are not yet mainstream? (3) Do the distinctive properties of Agentic LLMs suggest genuinely new cognitive design patterns?

Methodology

No experiments and no dataset — the method is structured comparative analysis. The authors curate a pattern catalog from prior comparative work, instantiate each pattern with ACT-R, Soar, and BDI examples (Tab.1, p.3), map recent Agentic LLM systems onto the same patterns (Tab.2, p.5), then run two detailed case audits (ReAct against observe-decide-act; Generative Agents against a nine-criterion episodic-memory specification adapted from Nuxoll and Laird 2012), argue two patterns are under-exploited, and nominate one new one. The authors state up front that an exhaustive survey per question is “too broad for a conference paper” (§3, p.4), so the examples are chosen to illustrate rather than to cover.

Method details
  1. Define the pattern (§2, p.2) — By analogy to software design patterns: an abstract, customizable description of a solution to a recurring design problem. A cognitive design pattern denotes a process/function or representation/memory that routinely recurs in agents and architectures, eliding both implementation and algorithm.
  2. Catalog (Tab.1, p.3) — Seven patterns: observe-decide-act; 3-stage memory commitment; hierarchical decomposition; short-term (context) memory; ahistorical KR/memory (semantic); historical KR/memory (episodic); procedural KR/memory — each with ACT-R, Soar, and BDI instantiations, plus retrieval and learning sub-rows (activation-mediated association, encoding specificity, chunking / production compilation).
  3. The worked pattern: 3-stage commitment (Fig.1, p.3) — Most systems store/erase in two stages. Many architectures instead use three: generate candidates for a memory slot, run a selection/commitment process to pick one, then allow reconsideration after commitment — which can end in retraction, deselection (the choice is demoted back to a candidate), or reaffirmation. BDI does this over plans/intentions, Soar over operators; Soar's reconsideration for one memory type is a specialized JTMS.
  4. Map (Tab.2, p.5) — Assign recent Agentic LLM systems to patterns. Footnote 3 concedes the list is 'purposely inclusive' and does not distinguish full from partial realizations of a pattern.
  5. Audit (§3.1, pp.5-7) — Two case studies. ReAct is aligned against the BDI observe-decide-act cycle (Fig.2, p.6). Generative Agents is scored against nine characteristics of episodic memory grouped into learning and retrieval (Tab.3, p.7).
  6. Predict (§3.2-3.3, pp.7-10) — Name two absent-but-apt patterns (reconsideration, knowledge compilation) with mechanism-level reasons for their absence, then nominate step-wise reflection as an LLM-native pattern and situate it against reconsideration, Self-reflection, and metacognitive reflection.

Main result

There is no headline number, because there is no experiment. The paper’s one concrete, checkable output is the Generative Agents audit: of nine characteristics of episodic memory, Generative Agents’ memory stream fully satisfies three (autobiographical, variable length, spontaneous retrieval), partially satisfies two, half-satisfies one, outright fails two, and one is unclear (Tab.3, p.7) — a system widely cited as the exemplar of LLM episodic memory, whose own authors, the paper notes, never claimed it was one (§3.1, p.6).

Key findings

  • ReAct instantiates observe-decide-act but drops the commitment stage (§3.1, p.5): it splits internal (thought) from external (action) steps, which is the observe and act halves, but nothing in the loop makes or holds an explicit commitment the way BDI intentions or Soar operator selection do. The authors turn this into a direct empirical question they do not run: would adding commitment beat plain ReAct (§3.1, p.6)?
  • Reconsideration is absent from mainstream Agentic LLMs, and there is a substrate-level reason (§3.2, p.8): chat-tuned LLMs resist major redirection of their own token trajectory, and LLMs alone are unreliable non-monotonic reasoners (citing Leidinger et al. 2024). Context-management schemes like MemGPT support redirection only indirectly, by forgetting or paging out past context — a workaround, not a belief-revision mechanism.
  • Knowledge compilation exists in LLM agents only as offline, translate-to-another-form caching, never as online compilation (§3.2, pp.8-9): Voyager compiles reasoning into executable JavaScript skills, LLMRG into structured graphs, Zhu and Simmons into Soar productions; Reflexion caches reflections but that buys within-task transfer with “little/no across-task transfer”; ExpeL comes closest of anything the authors found, yet requires an explicit training stage, “in sharp contrast with the online use of knowledge compilation for problem solving in ACT-R and Soar.”
  • A named prediction: the utility problem will resurface (§3.2, p.9): knowledge compilation only pays if similar situations recur and if memory plus retrieval stay cheap. Cognitive architecture spent decades on expensive-chunk mitigation (Minton 1990; Tambe et al. 1990), and the authors predict LLM agents will need the same specialized machinery once compilation becomes routine.
  • Step-wise reflection is nominated as a genuinely new pattern, and diagnosed as structurally fragile in the same breath (§3.3, pp.9-10): it emerges because LLM computation intermixes content and control rather than following a fixed architectural control flow, with self-consistency as its sophisticated instance. But the evaluator is the same unreliable generator, so the pattern is “possibly recursive and unbounded in the worst case”, and — the load-bearing distinction — it asks the model to judge correctness “without external/oracular feedback”, unlike Self-reflection (Renze and Guven), where an external process supplies the verdict, and unlike metacognitive reflection over whole trajectories (Soar retrospection, Reflexion).
  • The methodological claim underneath everything: the functional role, not the algorithm, is the right unit of comparison (§2, p.4) — Soar’s specialized JTMS and BDI’s decision-theoretic intention reconsideration look unrelated at implementation level and identical at role level, and only the role level generates transferable questions about LLM agents.

Implications

Positions cognitive design patterns as a complement to the Common Model of Cognition (Laird, Lebiere, Rosenbloom 2017), and proposes “Comparative Cognitive Architecture” as an emerging discipline (§4, p.10) — a functionally motivated catalog that, unlike the Common Model, does not care whether a pattern is human-plausible. The lineage it draws on is explicit and old: Soar and its chunking, ACT-R and production compilation, the BDI family, Doyle’s 1979 JTMS, Nuxoll and Laird’s episodic memory; on the LLM side it engages CoALA (Sumers et al. 2023) and Sypherd and Belle 2024 as the nearest prior attempts to import architecture lessons. The unrun ReAct-plus-commitment experiment is the cheapest testable claim in the paper and nobody in it runs it. Online knowledge compilation for LLM agents, with utility-problem control borrowed from Minton and Tambe, looks like a real open research line. The step-wise-reflection critique points straight at externally grounded verification as the fix — the paper identifies the disease (self-adjudication) and stops short of the cure.

Limitations

  • No experiments, no data, no code, no artifact of any kind: every claim is analytic and every “prediction” is unfalsified. The paper is honest about being a position paper, but that means nothing in it is evidence in the usual sense.
  • Deliberately non-exhaustive, by the authors’ own statement (§3, p.4): two case audits, seven patterns, and a Table 2 that footnote 3 admits is “purposely inclusive” and “does not distinguish full vs. partial realizations of cognitive design patterns.”
  • The catalog is asserted, not derived: the seven patterns come from the authors’ own long line of comparative analyses, with an ACT-R/Soar/BDI-centric selection bias, and the paper offers no criterion for what qualifies as a pattern, how patterns are individuated, or when a catalog is complete.
  • The audit rubric has no scoring definition: “Semi”, “Partial”, and ”?” in Tab.3 are unexplained judgments, and “Autobiographical: Yes” is granted even though memories are stored in the 3rd person. A second analyst could plausibly score this table differently.
  • Internal inconsistency on knowledge compilation: Tab.2 (p.5) lists it among patterns “evident in recent Agentic LLM research” with five exemplars, while §3.2 (p.8) opens by calling it one of two patterns “not yet been taken up in the Agentic LLM mainstream.” The footnote about partial realizations softens this but does not remove it.
  • Time-stamped snapshot: the state of the art surveyed is mid-2025, and the “not yet mainstream” claims are exactly the kind that decay fastest.
  • Whether human episodic-memory criteria should be requirements for an LLM agent is assumed rather than argued: the paper acknowledges Generative Agents never claimed to implement episodic memory, then scores it against nine human-memory characteristics anyway.

Critiques and Questions

  1. The diagnostic has no decision procedure. Nothing in the paper distinguishes “this system is missing a necessary function” from “this pattern is an artifact of symbolic architectures and does not apply to a substrate with in-context state.” A transformer that keeps a plan alive in context may be making an implicit commitment that is functionally adequate; the paper assumes an absent explicit stage is a deficiency without arguing the case.
  2. The single most testable claim in the paper — commitment-augmented ReAct beats ReAct — is posed and abandoned. Given three authors from the architecture that pioneered the commitment cycle, running it seems more valuable than describing it.
  3. How reproducible is Tab.3? Without a rubric, the audit’s persuasive force rests entirely on author authority, which is a weak foundation for a table presented as the paper’s main result.
  4. Step-wise reflection is diagnosed as unreliable because the evaluator inherits the generator’s unreliability, and the paper explicitly notes Self-reflection avoids this by taking feedback from “an external process.” That is the resolution, sitting one sentence away, and the paper does not follow it to its conclusion: reliability requires an arbiter that is not the model. This is precisely TDE’s premise, and it is somewhat striking that a paper from the cognitive-architecture tradition — where reconsideration is triggered by a truth-maintenance system operating over justifications, i.e. mechanically — does not observe that the LLM-agent field’s regression is having replaced a mechanical arbiter with a stochastic one.
  5. Small accuracy slip: §3.2 (p.9) attributes the Soar-production-generation work to “Zhu and Reid [70]”, but reference [70] is Zhu, F. and Simmons, R., Bootstrapping Cognitive Agents with a Large Language Model (AAAI 2024). Minor, but it is the kind of thing to check before citing the claim onward.
Why do the authors insist that Soar's JTMS and a BDI architecture's decision-theoretic intention reconsideration are 'the same thing', and what does that buy them when analyzing LLM agents?
Because both occupy one functional role — reconsideration, and more broadly belief revision and context/memory management — even though their algorithms and representations share nothing (§2, p.4). Abstracting to the role is what makes the commonality visible at all. The payoff is that the role becomes a slot you can check any system against: run Agentic LLM systems past the reconsideration slot and it is empty, which converts a vague intuition that LLM agents are brittle about changing course into a specific, named architectural gap with an associated research question.

Personal notes

Best use for TDE: this is an independent, cross-tradition corroboration of the gap, from people with no stake in the LLM-agent framing. Two quotable moves. (1) ReAct maps to observe-decide-act “but lacks the step that explicitly makes commitments” — a 40-year-old architectural cycle says the modern agent loop is missing its commit stage, which is a clean way to motivate compiling the instruction into an explicit, machine-checkable acceptance suite. (2) Step-wise reflection is “as potentially unreliable as the initial response”, “possibly recursive and unbounded”, and operates “without external/oracular feedback” — the tightest one-sentence statement of the circularity problem I have seen in the related-work pile, and it comes from the JTMS side of the house, where reconsideration was always mechanical.

Framing for the novelty defense: this paper diagnoses, TDE instantiates. It supplies the slot names (commitment, reconsideration) and the failure argument (self-adjudication), and stops there; it proposes no executable mechanism, no pre/postcondition gating, no state-diff grading, no benchmark. Cite it as motivation-side support, not as a competing method — there is no method here to compete with.
